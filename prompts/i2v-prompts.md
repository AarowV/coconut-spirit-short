# 图生视频提示词（通用版）

不绑定具体工具，中文提示词。只描述"怎么动"，不重复描述图片里已有的内容，这样人物和场景不容易走样。

## 一、通用设置

**统一后缀**（每条提示词末尾都加）：

```
电影级质感，浅景深，细腻胶片颗粒，青灰与暗金色调，黄昏逆光，运动自然流畅
```

**负面提示词**（工具支持就填）：

```
文字、水印、字幕、变形、面部扭曲、多余的手指、人物突然换脸、背景突变、镜头乱切
```

**生成策略**：每个镜头抽 3–4 条挑最好的。单段时长比分镜表多留 1 秒，剔头尾更好剪。台词不写进提示词，只描述"嘴在说话"，后期再对口型。

**没有首尾帧功能时**：镜 04、镜 06、镜 13 改成两段。前段用首帧加文字描述变化过程，后段用目标图当首帧反向缓慢起动，剪辑里用 0.2 秒叠化衔接。

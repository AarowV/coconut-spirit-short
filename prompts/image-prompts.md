# 图像提示词：定妆图、场景图、补图

所有提示词都带下面这条风格前缀（下文写作【前缀】）。人物图用纯深灰背景，方便后面当视频参考图；场景图用 16:9。

```
东方奇幻史诗电影质感，电影级调色，青灰与暗金主色调，逆光体积光，细腻胶片颗粒，写实质感，超高清
```

## 一、第一批：定妆图和场景图

**主角**
```
【前缀】。青年男子半身定妆照，约二十七八岁，面庞清瘦，眼神带好奇和一点贪心，头发随意束起。穿粗布短打，腰间束带，背着一根长竹竿。黄昏侧逆光，暖金色边缘光，纯深灰背景，正面站姿，人物居中，面部清晰，细节真实
```

**爸爸**
```
【前缀】。中年男子半身定妆照，约五十岁，身形沉稳，脸部线条硬朗，眼神平静里带一点老狐狸的狡黠，两鬓微白。穿与主角同款的粗布长衫，双手抱臂。黄昏侧逆光，纯深灰背景，正面站姿，面部清晰，细节真实
```

**凉薯形不倒翁**
```
【前缀】。一个椭圆形的不倒翁，形状像凉薯，上窄下圆，表面是暗金色，带细密的古老纹路，底部着地，放在圆形石台上，周围飘着细小的金色尘埃，黄昏逆光，浅景深
```

**泥人**
```
【前缀】。人形站立全身定妆照，头戴旧竹斗笠，身穿破烂的麻布衣，整个身体是流动的湿泥，泥浆顺着衣摆和手指缓缓滴落，表面有泥塑质感与液体反光，面部凹陷的眼窝，神情平静，脚下留着泥脚印。薄雾黄昏，纯深灰背景，正面站姿，细节真实
```

**场景：荒原石台**
```
【前缀】。16:9 大远景，黄昏的高原荒野，低伏的薄雾，远处山体剪影压着橘金色天际线，荒野中央有一圈古老的圆形石台，地面干裂，空气里漂着金色尘埃，航拍视角，开阔大气
```

**场景：雷暴云**
```
【前缀】。16:9 史诗大全景，天际线尽头一座高数千米的雷暴云砧，紫灰色云体镶着金边，闪电在云内明灭，荒原上两个渺小的人影走向它，低机位，压迫感与壮阔感并存
```

## 三、泥人修正版

初版问题：衣服轮廓太清楚，泥片像树皮，眼睛是黑洞；笑脸特写的泥浆半透明，像焦糖或蜂蜜。

**泥人修改**（参考：泥人全身定妆照）
```
以参考图为准，保持斗笠、整体轮廓和构图。弱化衣服和身体的界限，整个人由流动的湿泥构成，泥浆在肩、手臂、衣摆上缓缓下淌，有液态下垂感，像一尊正在融化又不断重塑的泥像。眼睛改成琥珀金色，带微光，神情平静而老练，细小的裂纹里透出暗金光。纯深灰背景，黄昏逆光
```

**泥人笑脸特写**（参考：泥人全身定妆照）
```
以参考图为准保持同一个泥人，面部特写，斗笠遮住上半脸，琥珀金色的眼睛，嘴角缓缓扬起一个淡淡的笑，脸颊有一块泥正在裂开掉落，泥浆下淌，黄昏逆光，浅景深
```

**泥人特写：泥浆改哑光**（参考：泥人笑脸特写）
```
以参考图为准，保持同一个泥人的脸、琥珀金色眼睛、斗笠和构图不变。把所有泥浆改成哑光、不透明的灰褐色湿泥，滴落的是稠厚的泥浆，不要透明感，不要焦糖或蜂蜜般的高光。金色边缘光只留在轮廓上，不要把整个泥浆染成金色。保留脸颊一块泥翘起、将要掉落的细节
```

**泥人全身（用新脸重出）**（参考 1：泥人笑脸特写修正版；参考 2：泥人全身初版）
```
同一个泥人，全身站立。以特写参考图为准保持脸和琥珀金色眼睛，以全身参考图为准保持斗笠、衣服轮廓和构图。整个身体由哑光不透明的灰褐色湿泥构成，衣服和身体融为一体，泥浆缓缓下淌，没有布料纹理和鳞片状泥片。纯深灰背景，黄昏逆光
```

## 四、出图时的注意点

- 主角和爸爸的脸型、发型、服装要有一眼能认出的区别，不然视频里容易混。
- 泥人如果生成得太像"人身上涂泥"，就把"流动的湿泥、液体反光"再加强，再多放一张近景脸部。
- 椰子的各张图要用同一颗椰子（同一个种子，或用上一张当参考图），不然前后变脸。
- 要做首尾帧变形的镜头（04、06、13），两张图的机位、构图、背景必须完全一致。
